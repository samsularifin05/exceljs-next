1 Generate & Test Fitur exceljs-next

Pilih fitur yang ingin diuji, lalu klik Generate & Download .xlsx atau langsung Generate & Inspect.

NEW
Menghitung lebar kolom otomatis berdasarkan isi sel, header, CJK/Unicode, dan ukuran font.
ENHANCED
Mendukung multi-pivot per workbook, 11 fungsi agregasi, multi-values, dan sourceTable.
NEW
Memisahkan halaman cetak secara horizontal setelah kolom tertentu (<colBreaks>).
NEW
workbook.protect() mengunci struktur tab sheet (tambah/hapus/rename). Centang ws.protect() jika ingin mengunci edit sel.
NEW
Mengenkripsi seluruh file .xlsx (AES-256 + SHA-512) sehingga Excel / WPS langsung meminta password saat file dibuka.
NEW
Menghitung tinggi baris otomatis untuk teks multi-baris (\n), wrapText, dan ukuran font.
NEW
Membuat sheet baru JSON Users langsung dari array of objects dan membaca kembali lewat ws.toJSON() di Inspector.
NEW
Mengisi placeholder {{invoiceNo}} & mengekspansi baris array {{items.name}} pada sheet Invoice Template.
NEW
Menyisipkan grafik native Excel langsung di sebelah tabel data pada sheet Sales Report.
